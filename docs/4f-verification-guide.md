This guide explains how to help users complete Phase 4F live verification:
- Swap the Prism instance jar from questbridge-0pre.1.jar to questbridge-0pre.2.jar
- Configure the minecraftToken in config/questbridge-client.toml
- Start the host and launch Minecraft client
- Verify the overlay appears in OBS with proper chroma keying
- Run the verification checklist to confirm all Phase 4 milestones are met
